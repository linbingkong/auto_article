# 公众号自动发文智能体 —— 实现方案调研报告

> 目标：每天自动选择热点题材 -> 生成公众号文章与配图 -> 发布到公众号。
> 调研范围：热点选题采集、AI 写作、AI 配图、公众号发布全链路；调研时间 2024-2026 口径；供后续架构设计参考。

## 0. 总体结论（摘要）

1. **技术路线已成熟**：热点选题、AI 写作、AI 配图、公众号发布四个环节都有大量成熟开源方案与免费数据源，自研一套"日更智能体"完全可行。
2. **发布通道只有一个合规正路**：微信官方 API（access_token → 素材上传 → draft/add 草稿箱 → 可选 freepublish 发表）。官方接口无定时参数，定时需外部调度（cron / GitHub Actions / 云函数 / OpenClaw 定时任务）。模拟登录属违规高风险路径，不建议生产使用。
3. **形态选择**：自研 Python/Node 流水线（可控性最强）｜ OpenClaw + Skill 生态（baoyu-skills 25k★、16Miku、wechat-flow、jiji262/wechat-publisher 等，社区最流行）｜ 低代码（Coze/Dify/n8n，非程序员首选）。
4. **成本极低**：DeepSeek-V3.2-Exp 写作单篇约 0.03-0.05 元；国内文生图 0.1-0.5 元/张；封面可用 Pillow/HTML 模板合成接近零成本。
5. **最大风险是合规而非技术**：微信 2025 年起打击"非真人自动化创作"、2025-08 起 AI 内容需主动声明并加标识、2026-04 检测维度扩展到 AI 率/同质化/低创作。**建议设计为"AI 生成 + 人工审核确认"的半自动模式**：AI 完成选题/写作/配图/排版并投递到草稿箱，人工在后台点"发表"（多数成熟项目如 16Miku、fengyun-publish 的默认策略正是如此）。

## 1. 全链路架构总览

典型的"公众号自动发文智能体"由以下环节组成：

热点选题采集 -> 选题筛选/评分 -> AI 写作（大纲->正文->润色）
    -> AI 配图/封面生成 -> 排版（Markdown->公众号富文本）-> 发布（草稿箱/直接发布）
    -> 定时调度（每日触发）-> 数据归档/效果追踪

- 实现形态分为几大类：自研脚本/Python 流水线、Agent 框架（OpenClaw/MCP Skill）、低代码平台（Coze/Dify/n8n）、开源全链路项目。

### 3.2 推荐写作流水线（多阶段 Agent）
1. 选题/定位：生成 5-10 个候选选题 + 关键词
2. 大纲生成：标题、导语、3-6 个章节、每节要点
3. 分节写作：逐节生成（控制上下文长度，避免长文失控）
4. 合并衔接：统一人称、语气、过渡句
5. 润色去 AI 味：口语化、删套话、加具体案例数字
6. 标题优化：生成 5+ 候选（悬念式/数字式/痛点式）
7. 排版：Markdown → 公众号 HTML

- Pexels / Unsplash / Pixabay：免费 API，可商用；缺点是与内容匹配度不可控，适合兜底配图，核心封面建议文生图或模板合成

### 4.3 封面自动合成
- **Pillow（Python）**：标题文字+渐变背景+装饰，一键输出封面
- **HTML 转图**：CSS 设计模板 + html2image/Playwright 截图，样式自由度最高
- **baoyu-skills 配图 skill**：基于 Pillow 自动生成封面/信息图/九宫格，现成实现
- **尺寸要求**：首图 900x383（2.35:1，留安全边距），小图 200x200，正文配图宽 900、单图 <=10MB

### 4.4 原创/查重合规
- 原创声明条件：>=300 字、无抄袭；平台不直接检测"是否 AI 生成"，原创校验基于相似度比对
- AI 实质原创内容可通过校验；高度雷同的模板化 AI 水文会被打回
- **2026-04 新规**：微信明确打击"非真人自动化创作"，检测维度扩展为 AI 率/同质化/低创作/原创度/标题封面
- 实操：AI 当"助理"不当"枪手"（人工选题+深度编辑+个人观点）、控制发布频率、封面尽量原创、重要账号先草稿箱人工审核

## 5. 公众号发布环节（关键技术约束）

### 5.1 官方 API 是唯一合规路径（推荐）
核心链路：取 token -> 上传素材 -> 建草稿 -> 发布 -> 查状态
1. 获取 access_token：
   - 经典：GET /cgi-bin/token?grant_type=client_credential&appid=..&secret=..，有效期 2 小时，每日调用有上限（超限返回 45009）
   - 推荐稳定版：POST /cgi-bin/stable_token（默认复用缓存，force_refresh=true 才强制刷新，规避频控）
2. 草稿箱：POST /cgi-bin/draft/add（title/content/thumb_media_id/author/digest...）-> 返回草稿 media_id；draft/update 可更新
3. 发布：POST /cgi-bin/freepublish/submit（参数 media_id）-> 异步执行，返回 publish_id；轮询 freepublish/get 确认 article_status=成功
4. 素材：material/add_material(type=image) 传封面得到 thumb_media_id；material/uploadimg 传正文图片得到 URL（不占素材库数量）
5. 权限：发布能力对订阅号/服务号均开放；素材接口（material/*）通常要求认证；群发（mass/*）一般要求服务号+认证

### 5.2 发布 vs 群发（关键区别）
- 发布（freepublish）：发表到公众号主页，不推送粉丝、不占群发次数、一天可多次 -> 适合高频自动化
- 群发（mass send）：推送给所有粉丝，受次数限制（订阅号每天 1 次、服务号每月约 4 次）

### 5.3 定时发布
- 官方接口无定时参数（freepublish/submit、draft/* 都没有）；后台 UI 定时能力仅覆盖「群发」（定时群发，占用群发次数）
- 定时发布 = 外部调度器 + 官方发布接口：
  - GitHub Actions schedule（cron）：免费、日志可审计
  - APScheduler / cron（本机或 VPS）
  - 云函数定时器（腾讯 SCF / 阿里 FC / AWS Lambda）
  - n8n Schedule Trigger
- 工程要点：发布是异步的，需轮询 freepublish/get 确认上线；token 2 小时内缓存复用

### 5.4 第三方开源封装（都是官方 API 的封装，合规）
- wxgzh-cli（fanbuz/wxgzh-cli）：公众号开放平台 CLI，「agent friendly」，Markdown->草稿->发布
- wechat-publisher（jiji262/wechat-publisher）：Claude/Agent Skill 形态
- @jesonliu/publish-mcp-server：MCP Server，AI 对话工具可直接发布
- @ziikoo/woa：Node SDK/中间件
- 16Miku/wechat-auto-publishing：完整自动发文工作流 Skill（环境准备->资讯->写稿->图片->草稿->发布->归档->定时调度）
- wenyan-cli（文颜）：Markdown->公众号排版/发布工具链，社区评价「最佳现代方案：wenyan-cli + GitHub Actions 自动发布草稿」

### 5.5 非官方路径（违规，高风险）
- 模拟登录 mp.weixin.qq.com（Playwright/DrissionPage 扫码+无头浏览器）或微信客户端协议（itchat/Wechaty）
- 风险：封号（微信 2025 明确打击 AI 自动化创作/代笔）、验证码频繁失效、后台接口易变、违反《运营规范》
- 仅适用：无 API 权限的未认证个人号低频兜底；不建议生产级高频发布

### 5.6 企业微信不能发布公众号
- 企业微信与公众号是两个独立体系；webhook 只能推送企业微信群消息
- 合理用法：作为发布成功后的通知渠道

### 5.7 接口调用额度
- 官方《接口调用额度说明》：https://developers.weixin.qq.com/doc/subscription/guide/dev/api/limit
- 草稿/发布/素材接口每日调用量有上限，需配额管理与失败重试

### 5.8 排版（Markdown -> 公众号富文本）
- doocs/md：开源微信 Markdown 编辑器（自定义主题、图床、AI 助手）：https://github.com/doocs/md
- md2wechat（npm）：Markdown 转公众号格式的 API/CLI：https://www.npmjs.com/package/md2wechat
- md2wechat-skill：一键排版发布 CLI，40+ 排版样式、AI 配图、批量发布、多账号：https://github.com/geekjourneyx/md2wechat-skill

### 5.9 政策与合规风险（重要！2025 年新规）

  - https://news.ifeng.com/c/8sBtSYsvWPn
- 2025-08 起：发布 AI 生成合成内容需「主动声明」，平台添加显式+隐式标识：

  - https://m.ithome.com/html/879650.htm

### 6.3 通用工程经验（来自各项目 CLAUDE.md/README 实测）
- 凭证铁律：AppID/AppSecret 永不入库、不进 Skill 包；IP 白名单必配（常见错误 40164）

## 7. 低代码平台方案

- **Coze（扣子）**：官方/社区有"公众号文章生成+排版+发布"工作流模板（热点抓取→LLM 仿写→图片生成→排版→发布草稿箱），内置微信公众号发布插件；零代码，最快出效果。参考：https://juejin.cn/post/7616644308808433664 、https://developer.volcengine.com/articles/7543193056548225033
- **Dify**：编排 Agent 写作 + RAG 知识库（可挂账号历史文章做风格库），通过 HTTP 节点调公众号 API
- **n8n**：Schedule Trigger 定时 + 公众号发布节点/HTTP 请求，自托管免费
- **局限**：低代码平台的"发布"节点一般也只到草稿箱；高峰期模板质量参差，需自己调提示词

## 8. 推荐技术选型建议

### 8.1 推荐架构（自研 + 成熟组件组合）
- 定时调度：GitHub Actions cron / APScheduler / 云函数定时器，每日触发
- 热点选题：知乎热榜 + 微博热搜 + 头条热榜 + 财联社电报（公开 JSON 接口），白名单/黑名单 + 热度阈值 + SEO 评分过滤，输出 1-3 个候选选题
- AI 写作：DeepSeek-V3.2-Exp 多阶段流水线（大纲→分节→合并→润色→标题优化），单篇成本约 0.03-0.1 元
- AI 配图：通义万相/豆包 Seedream 生成封面+正文图（约 0.1-0.5 元/张）；封面 900x383 也可用 Pillow/HTML 模板合成（近零成本）
- 排版：Markdown → 公众号 HTML（doocs/md 或 wenyan 工具链）
- 发布：官方 API：stable_token → material/uploadimg + add_material → draft/add 草稿箱
- 通知：飞书/企业微信 webhook 推送"草稿已就绪"
- 人工确认：管理员在 mp 后台审阅并点"发表"（合规红线，勿无人值守 freepublish）
- 复盘（可选）：阅读数据回填，反哺选题

### 8.2 快速起步选项
- 想直接抄作业：OpenClaw + baoyu 三件套（baoyu-cover-image / baoyu-article-illustrator / baoyu-post-to-wechat）或 16Miku/wechat-auto-publishing（草稿+飞书通知+人工发表），ClawHub 一键安装
- 想要完整热点→写作流水线：wechat-flow（全链路最完整）或 jiji262/wechat-publisher（带反 AI 味 gate，231★）
- 非程序员：Coze 工作流模板（公众号生成+排版+发布）
- 只缺排版+发布环节：wenyan（@wenyan-md/cli 或 wenyan-mcp）
- 深度技术内容路线：ccblog（质量上限最高，成本最高）

### 8.3 落地前提清单
- 公众号 AppID/AppSecret + 服务器 IP 白名单（常见坑 40164）；素材接口一般需认证号
- token 用 stable_token 稳定版 + 2 小时缓存；发布异步，需轮询 freepublish/get
- 图片约束：API 传图限 1MB、不支持 WebP（45166/40113）；封面 900x383、小图 200x200
- 合规：AI 内容主动声明、保留人工终审、控制频率、避免同质化模板化文章（微信 2026-04 起从严治理"非真人自动化创作"）
