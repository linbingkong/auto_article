# 公众号写作框架公开样本调研

## 研究边界

本调研仅使用公开可访问的转载页、聚合页和行业访谈，没有绕过公众号登录或付费限制。第三方转载可能修改标题、配图或排版，搜索结果也偏向高传播文章，因此结论只用于提炼通用的信息组织方法，不代表账号全部作品，也不用于复刻任何作者的独特措辞。

## 原创融合框架

### 1. 开头：具体事实与核心问题

前 120 字给出证据中最具体、反常或有现实后果的事实，并提出文章真正要回答的机制问题。没有现场材料时不得虚构人物动作、对话或气氛。

### 2. 正文：叙事线与解释线交替

- 叙事线：人物或机构、时间节点、关键转折，只保留改变因果链的节点。
- 解释线：利益、制度、技术、供应链、成本与约束。
- 重要段落采用“事实/数据—来源归因—机制解释—影响与边界”。
- 类比之后补充不适用边界；多方博弈分别说明目标、资源、成本和约束。

### 3. 按题材选择骨架

- 财经：变化 → 传导链 → 受益与承压群体 → 边界条件 → 指标。
- 国际与历史：当前事件 → 必要历史节点 → 各方利益、能力和约束 → 转折 → 有限判断。
- 科技产业：新变化 → 同口径比较 → 技术/供应链/商业机制 → 用户与行业影响 → 未验证变量。
- 社会议题：具体事件 → 各方说法 → 规则与行为激励 → 受影响群体 → 同类材料与反例 → 不过度外推的结论。

### 4. 结尾：可验证而非强行升华

回到开头问题，分别交代有证据的结论、仍未知的变量和一个后续观察指标。可以提出具体讨论问题，但不用警句、口号或必然性预测制造完成感。

### 5. 标题：承诺解释而不是预支结论

可使用数字钩子、事实反差、结果前置、时间纵深、机制问题等方法。禁用没有高强度证据支持的“崩了、炸了、罪魁祸首、一切结束”等绝对化表达；单方说法和预测必须保留归因或条件。

## 明确不采用的特征

- 不复制账号惯用句、口头禅、修辞和段落文本。
- 不使用粗俗标签、群体刻板印象、战争化行业比喻或无证据的动机推断。
- 不用强情绪标题掩盖证据不足。
- 不将个人案例直接升级成社会趋势。
- 不把时间先后、利益一致或人物性格写成已经证明的因果。
