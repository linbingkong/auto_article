# 观思辩明智能体网站推广方案与模板

> `[网站地址]`、`[二维码]`、`[案例数据]` 为待替换项；次数和价格以后台配置为准。

## 一、推广定位

**一句话定位：**观思辩明是面向微信公众号创作者的选题研究、文章生成、配图与草稿管理智能体。

**主口号：**从热点到草稿，一站式完成。

**价值主张：**
- 结果：更快找到值得写的话题，形成可继续编辑的文章初稿；
- 流程：榜单筛选、榜单外搜索、资料研究、文章生成、配图、编辑与草稿箱推送；
- 管理：角色权限、文章归属、平台额度、个人 API、注册审批和审计日志；
- 边界：AI 完成重复工作，事实、观点和正式发布仍由人工把关。

避免宣传“自动爆文”“保证10万+”“完全替代编辑”。

## 二、目标用户

1. **个人公众号创作者**：选题慢、更新不稳定。话术：从选题到草稿箱，一条流程完成。
2. **企业新媒体运营**：工具分散、制作环节多。话术：把重复工作交给智能体，把判断留给运营。
3. **工作室/代运营团队**：多账号协作和权限混乱。话术：不仅生成文章，也管理内容资产和团队。
4. **私有化部署用户**：关注数据和密钥边界。话术：部署在自己的服务器，内容和配置由自己掌控。

## 三、30/60/90天目标

| 周期 | 重点 | 建议目标 |
|---|---|---|
| 1–30天 | 验证定位和种子用户 | 300访问、60申请、30审批、15人完成首篇 |
| 31–60天 | 案例与口碑 | 100累计用户、40周活、10个案例/评价 |
| 61–90天 | 渠道和付费 | 300累计用户、80周活、20–40付费用户 |

核心指标：注册申请率、首次生成率、7日复用率，而不是单纯访问量。

## 四、推广漏斗

1. **认知**：发布公众号选题、资料检索、AI初稿校对等方法内容。
2. **兴趣**：准备60秒演示视频、完整生成案例、产品流程图。
3. **注册**：扫码关注 → 填写申请 → 私信手机号 → 管理员审批 → 领取体验次数。
4. **激活**：只引导完成一个目标——生成并打开第一篇文章。
5. **留存**：第1天教程、第3天选题模板、第7天案例；7天未使用只召回一次。
6. **付费**：先提供低门槛体验包，再引导购买额度；若管理员开放，也可使用个人API。

## 五、渠道策略

### 微信生态（最高优先级）
- 公众号每周2篇：1篇方法论、1篇真实案例；
- 朋友圈每周3–4条：过程40%、方法30%、案例20%、活动10%；
- 微信群先分享方法和案例，再发体验邀请，避免刷屏；
- 视频号以屏幕录制为主，直接展示“输入关键词后发生了什么”。

### 内容平台
- 小红书：公众号选题荒、AI写作流程、运营效率工具；
- 知乎：回答“如何提高公众号产能”“如何找选题”等高意图问题；
- B站：5–10分钟完整工作流演示与真实评测。

### 合作渠道
- 邀请20位1千–5万粉垂直创作者体验；
- 为新媒体/AI社群提供免费直播；
- 给代运营团队提供7–14天定向体验；
- 与服务器、API、排版工具社群做内容互换。

## 六、30天执行排期

### 第1周：素材准备
- 确定统一口号和视觉；
- 录制60–90秒演示；
- 准备科技热点、商业解读、方法论3个真实案例；
- 实测注册、审批和首次生成流程；
- 建立渠道数据表。

### 第2周：种子测试
- 邀请30–50位公众号创作者；
- 每天1条朋友圈案例；
- 进入3–5个精准社群；
- 回访每位完成首篇文章的用户。

### 第3周：案例扩散
- 发布完整案例长文、2篇小红书、1条视频号；
- 收集5条真实评价；
- 上线转介绍活动：双方各赠体验次数。

### 第4周：转化复盘
- 举办一场30–45分钟线上演示；
- 召回体验后未复用用户；
- 上线小额体验包；
- 停止低质量渠道，将最佳案例做成固定落地页。
